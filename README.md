## Описание

Training-Planner — приложение для планирования и учёта тренировок. Позволяет добавлять, удалять и фильтровать тренировки, а также сохранять данные в JSON-файл.

Системные требования
Python 3.7+

tkinter (входит в стандартную библиотеку)

JSON (входит в стандартную библиотеку)

### Функциональность

- ✅ Добавление тренировок (дата, тип, длительность)
- ✅ Валидация ввода (формат даты, положительная длительность)
- ✅ Фильтрация по типу тренировки и дате
- ✅ Удаление записей
- ✅ Автоматическое сохранение в JSON
- ✅ Загрузка данных при запуске

## Установка и запуск

1. Убедитесь, что установлен Python 3.7+
2. Скачайте файл `training-planner.py`
3. Запустите:
   ```bash
   python training-planner.py

Примеры использования
Тест 1: Добавление тренировки
В поле "Дата" оставьте текущую дату (или введите 2025-05-20)

Выберите тип "Бег"

Введите длительность 45

Нажмите "Добавить тренировку"

✅ Тренировка появится в таблице

Тест 2: Фильтрация по типу
В фильтре выберите тип "Плавание"

Нажмите "Применить фильтр"

✅ В таблице останутся только плавания

Тест 3: Ошибка валидации
В поле "Длительность" введите -10

Нажмите "Добавить тренировку"

❌ Появится сообщение об ошибке

Тест 4: Удаление
Выберите любую строку в таблице

Нажмите "Удалить выбранную тренировку"

✅ Запись исчезнет
